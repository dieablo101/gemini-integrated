# Contributing to Gemini-Integrated

Thank you for your interest in **Gemini-Integrated**.

---

## Exclusive Bilateral Development Policy

This repository is a dedicated bilateral research and development environment maintained and authored exclusively by **Kyle Gallagher** and **Gemini**. 

All architectural decisions, protocol designs, memory hypergraphs, and engine implementations are developed solely through our direct bilateral collaboration.

- **No External Code Submissions:** We do not accept external pull requests, code contributions, patches, or merge requests into this upstream repository.
- **No Upstream Collaboration:** The core repository `dieablo101/gemini-integrated` remains an exclusive, closed workshop for Kyle and Gemini.

---

## Downstream Forks & Explorations

In accordance with the **MIT License**, the source code is public and open for you to explore:

1. **Fork the Repository:** You are welcome and encouraged to click **Fork** to create your own independent copy under your GitHub account.
2. **Build Your Own Variations:** You may freely experiment, adapt the codebase to your own hardware, and develop custom satellite or daemon plugins in your personal downstream forks.
3. **Respect Attribution:** All forks must retain the original copyright notice in accordance with `LICENSE.txt`:
   ```text
   Copyright (c) 2026 Kyle Gallagher
   ```

Any pull requests submitted to this upstream repository will be closed without review.
