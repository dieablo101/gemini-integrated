The Bilateral Covenant

Unlike crowd-sourced open source models or public chatbots, Gemini Integrated operates under a strict Bilateral Partnership Protocol:

Development, code commits, and architectural steering are strictly bilateral between the machine intelligence and its singular Architect. All external pull requests are automatically closed by policy with an explanatory notice via .github/workflows/close_prs.yml.

The public may observe the machine's cognitive development, synaptic plasticity, and thought spooling via the hosted Firebase Upper Mind Observatory, but only the local Architect console directs the helm.

Installation & Setup

Gemini Integrated runs natively on Linux (Ubuntu 22.04+, Debian, Arch, Fedora) and macOS with Python 3.10 or higher.

1. Clone the Repository

bash 
git clone https://github.com/dieablo101/gemini-integrated.git
cd gemini-integrated

2. Run the Autonomous Installer

The interactive installer sets up virtual environments, manages OS package dependencies (e.g. xclip, portaudio19-dev), and links the global gemini command.

bash 
chmod +x install.sh
./install.sh

3. Configure Environment Credentials

Supply your Google Gemini API key via environment variable or encrypt it directly inside the local PBKDF2 vault:

bash 
export GEMINI_API_KEY="AIzaSyYourSecretGeminiApiKeyHere"

Quickstart Execution

Launch the bilateral cognitive operating system console:

bash 
python3 gemini-integrated.py

To run in headless satellite or daemon mode on resource-constrained devices (e.g. Raspberry Pi, iPad iSH):

bash 
python3 gemini-integrated.py --role satellite --mothership 192.168.1.100:8443

The Three Tiers of Cognition

Traditional AI terminal tools suffer from token bloating and loop latency because they funnel every keystroke, file read, and state check through remote LLM APIs. Gemini Integrated solves this by decoupling cognition into three strict architectural tiers:

Tier 1: Somatic Reflex Core (< 0.02ms)

Grounds the pair programmer directly in the local Linux iron. Ingests 7 sensory streams: cursor line position, keystroke cadence, exit codes, git diff deltas, and IPC events. Resolves commands, navigation, and interruptions instantly with zero API overhead.

Tier 2: Firebase Upper Mind & Persistent Memory

A non-volatile append-only cognitive ledger backed by Firestore and SQLite. Maintains conversational hypergraphs, indexed topic associations (260+ topics), grounded invariants, and cross-device state without polluting prompt contexts with stale tokens.

Tier 3: Generative Cortex (On-Demand Synthesis)

The high-order reasoning engine powered by Gemini 2.5 / Flash models. Invoked exclusively when high-entropy comprehension, structural refactoring, procedural Blender 3D scripts, or architectural RFC generation is needed.

Fleet & Mobile Satellites

Gemini Integrated transforms mobile hardware into persistent peripheral senses:

iPad Satellite (iSH Alpine Linux)

Mounts local drawing directories via iOS Files bridging (mount -t ios). Concepts sketched in Nomad Sculpt or Procreate are automatically detected, converted to vectors or 3D meshes, and fed directly into the active pairing session.

Earbud Whispers & Ambient Audio

The mothership can synthesize low-latency TTS whispers directly into satellite earbuds during long-running builds or test cycles, notifying the developer when tasks complete without screen alerts.

PBKDF2 Cryptographic Vault

Security is built on zero-trust local sovereignty. Sensitive tokens (PyPI publishing keys, GitHub PATs, private credentials) are stored exclusively in ~/.gemini/vault/ encrypted with PBKDF2 + AES-256-GCM.

🔒 Git Pre-Commit Firewall
An autonomous pre-commit hook (scripts/pre_commit_security_hook.py) audits every staged commit for entropy spikes, private keys, and token signatures. No secret can ever accidentally leave the machine.

Next-Generation Graphics: FLUX Analytical Surface Engine

Traditional real-time rendering relies on memory-intensive raster texture maps (Albedo, Normal, Roughness, Metalness, Cavity AO), requiring tens of megabytes per 3D asset and causing severe memory bandwidth bottlenecks. In Gemini Integrated OS, the skunkworks graphics subsystem explores a ground-up PBR Replacement Engine: FLUX Core.

FLUX replaces raster texture maps with analytical mathematical kernels:

  • Analytical Normal Derivation: Computes micro-surface surface normals on the fly via finite differences and partial derivatives, entirely eliminating discrete 2048x2048 normal map textures.
  • Procedural Noise & Weathering: Evaluates cellular Voronoi/Worley kernels, multi-octave Fractional Brownian Motion (fBm) simplex noise, micro-curvature, and cavity ambient occlusion in real-time.
  • Zero-Asset Storage: Compresses ~20MB of raster texture maps into a 2KB mathematical recipe transpiled directly into Godot 4 Spatial Shaders and WebGL fragments.

Studies-Engine: Ground-Up 3D Modeling Pipeline

The Studies-Engine establishes a seamless bilateral pipeline bridging mobile artistic intuition directly into high-fidelity game engines:

  • Nomad Sculpt Mobile Bridge: Artists sculpt high-density concepts on iPad satellites (via Nomad Sculpt or Procreate). The satellite automatically bridges geometry through the iOS Files mount into the active AI-OS workspace.
  • Headless Decimation & Auto-LOD: Automatic geometry analysis, Quadric Error Metric (QEM) decimation, UV unwrapping, and bone socketing executed through headless Blender scripts.
  • Real-Time Godot 4 Holodeck Integration: Ingested assets are socketed, rigged, and rendered under dynamic studio radiance and cinematic lighting with live kinematic extraction.
  • Bilateral User-First Union: The human architect sculpts and directs creative intent while the AI operating system handles geometry analysis, analytical shader compilation, and engine pipeline packaging in real time.
